# 🧮 Calculator Web App

A **modern, responsive calculator** built with pure HTML5, CSS3, and Vanilla JavaScript — designed as a portfolio project for a Web Developer / Software Developer position.

---

## 🖥️ Live Preview

> Open `index.html` directly in any modern browser — no server or build step required.

---

## 🚀 How to Run

1. **Clone or download** this repository
2. Open the `calculator-app/` folder
3. Double-click **`index.html`** (or right-click → Open with browser)

No installation. No build process. No internet required.

---

## 📁 Project Structure

```
calculator-app/
│
├── index.html          # Main HTML (semantic, ARIA-ready)
├── css/

├── js/

```

## ⌨️ Keyboard Shortcuts

The calculator supports keyboard input for faster interaction.

| Key | Action |
|---|---|
| `0 - 9` | Enter numbers |
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `Enter` or `=` | Calculate result |
| `Backspace` | Delete the last character |
| `Escape` | Clear calculator |
| `%` | Percentage |
| `.` | Decimal point |

## 🔬 Scientific Functions

The calculator includes an expandable Scientific mode for advanced mathematical calculations.

| Button | Function |
|---|---|
| `sin` | Sine |
| `cos` | Cosine |
| `tan` | Tangent |
| `√` | Square root |
| `x²` | Square |
| `xʸ` | Power |
| `log` | Base-10 logarithm |
| `ln` | Natural logarithm |
| `π` | Pi constant |
| `e` | Euler's number |

Click the **Scientific** button at the bottom of the calculator to expand or collapse the scientific functions.
